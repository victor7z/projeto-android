# História do Android 🤖

Página criada no **Capítulo 17** do curso de HTML5 e CSS3 do **Curso em Vídeo** (professor Gustavo Guanabara). Ela conta a história do mascote do Android, o **Bugdroid**, e traz a curiosidade das versões do sistema batizadas com nomes de doces.

> ⚠️ Apesar do nome, **não é um aplicativo Android**. É uma página web feita com HTML e CSS.

## 🧩 O que a página tem

- Cabeçalho, menu de navegação e rodapé
- Artigo com títulos, parágrafos, imagens e links externos
- Vídeo incorporado do YouTube
- Barra lateral (`aside`) com a lista de versões do Android
- Estilos em arquivo CSS externo e fontes personalizadas

## 🎯 O que pratiquei

- Estrutura semântica (`header`, `nav`, `main`, `article`, `aside`, `footer`)
- Textos, listas, links e imagens em HTML
- Estilização com CSS externo
- Incorporação de vídeo com `iframe`

## 🛠️ Tecnologias

HTML5 · CSS3

## ▶️ Como ver

Baixe o repositório e abra o arquivo `index.html` no navegador.
